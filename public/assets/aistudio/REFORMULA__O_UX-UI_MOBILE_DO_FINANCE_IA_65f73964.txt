# 2. PADRÃO VISUAL OBRIGATÓRIO

Mantenha a identidade visual original do FINANCE IA.

### Paleta de cores

- Azul-marinho principal: #14263d.
- Azul secundário: #1d3552.
- Verde de sucesso: #059669.
- Fundo geral: #f3f5f8.
- Cartões: #ffffff.
- Texto principal: #172536.
- Texto secundário: #64748b.
- Bordas: #e5eaf0.
- Vermelho: utilizar somente para despesas, erros e alertas.

Não introduza cores aleatórias nem altere desnecessariamente a identidade visual.

### Tipografia

Adotar:

- Títulos principais: 22–26 px.
- Títulos de cartões: 16–18 px.
- Textos normais: 14–16 px.
- Textos auxiliares: 12–14 px.
- Botões: 14–16 px.

Evitar textos de 10 px em funcionalidades importantes.

### Ergonomia

Utilizar como referência:

- Área mínima de toque: 44 × 44 px.
- Botões principais: 48–56 px de altura.
- Campos de entrada: 48–56 px.
- Margens laterais: 16–20 px.
- Espaçamento entre controles: 8–12 px.
- Navegação inferior: 64–76 px, além da área segura do dispositivo.

# 4. REFORMULAÇÃO DA NAVEGAÇÃO INFERIOR

Arquivo:

`src/components/MobileBottomNav.tsx`

A navegação atual deve ser substituída por uma barra inferior mais ergonômica.

### Nova organização

Cinco posições:

1. Início.
2. Movimentações.
3. Adicionar.
4. Boletos.
5. Mais.

O botão Adicionar deve receber destaque visual.

O botão Mais deve abrir um Bottom Sheet com os demais módulos.

### Código de referência

```tsx
import React, { useState } from 'react';

import {
  Home,
  ArrowLeftRight,
  Plus,
  Receipt,
  Menu,
  X,
  Wallet,
  CreditCard,
  Landmark,
  ChartNoAxesCombined,
  FileText,
  Brain,
  Settings,
  Package,
  CalendarDays
} from 'lucide-react';

interface MobileBottomNavProps {
  currentTab: string;
  setCurrentTab: (tab: string) => void;
  onOpenNew: () => void;
}

export const MobileBottomNav: React.FC<
  MobileBottomNavProps
> = ({
  currentTab,
  setCurrentTab,
  onOpenNew
}) => {
  const [moreOpen, setMoreOpen] = useState(false);

  const modules = [
    { id: 'accounts', label: 'Contas bancárias', icon: Landmark },
    { id: 'cards', label: 'Cartões', icon: CreditCard },
    { id: 'debts', label: 'Dívidas', icon: Wallet },
    { id: 'planning', label: 'Planejamento', icon: CalendarDays },
    { id: 'assets', label: 'Patrimônio', icon: Package },
    { id: 'documents', label: 'Documentos e Scanner', icon: FileText },
    { id: 'imports', label: 'Extratos e Open Finance', icon: Receipt },
    { id: 'ai', label: 'Inteligência Artificial', icon: Brain },
    { id: 'reports', label: 'Relatórios', icon: ChartNoAxesCombined },
    { id: 'settings', label: 'Configurações', icon: Settings }
  ];

  const navigate = (tab: string) => {
    setCurrentTab(tab);
    setMoreOpen(false);
  };

  return (
    <>
      <nav
        className="
          md:hidden fixed bottom-0 inset-x-0 z-40
          bg-white border-t border-slate-200
          grid grid-cols-5 items-center
          px-2 pt-2
          pb-[calc(8px+env(safe-area-inset-bottom))]
          shadow-[0_-4px_18px_rgba(0,0,0,0.06)]
        "
        aria-label="Navegação principal"
      >
        <button
          onClick={() => navigate('dashboard')}
          className="min-h-12 flex flex-col items-center justify-center gap-1"
        >
          <Home size={22} />
          <span className="text-xs font-medium">Início</span>
        </button>

        <button
          onClick={() => navigate('cpf')}
          className="min-h-12 flex flex-col items-center justify-center gap-1"
        >
          <ArrowLeftRight size={22} />
          <span className="text-xs font-medium">Movimentações</span>
        </button>

        <button
          onClick={onOpenNew}
          className="
            w-14 h-14 -mt-5 mx-auto
            rounded-full bg-[#14263d]
            text-white shadow-lg
            grid place-items-center
            active:scale-95 transition
          "
          aria-label="Adicionar lançamento"
        >
          <Plus size={27} />
        </button>

        <button
          onClick={() => navigate('boletos')}
          className="min-h-12 flex flex-col items-center justify-center gap-1"
        >
          <Receipt size={22} />
          <span className="text-xs font-medium">Boletos</span>
        </button>

        <button
          onClick={() => setMoreOpen(true)}
          className="min-h-12 flex flex-col items-center justify-center gap-1"
          aria-label="Abrir outros módulos"
          aria-expanded={moreOpen}
        >
          <Menu size={22} />
          <span className="text-xs font-medium">Mais</span>
        </button>
      </nav>

      {moreOpen && (
        <div className="md:hidden fixed inset-0 z-50">
          <button
            className="absolute inset-0 bg-slate-950/50"
            onClick={() => setMoreOpen(false)}
            aria-label="Fechar menu"
          />

          <section
            className="
              absolute bottom-0 inset-x-0
              bg-white rounded-t-3xl
              p-5 pb-[calc(24px+env(safe-area-inset-bottom))]
              max-h-[85dvh] overflow-y-auto
              animate-in slide-in-from-bottom
            "
            role="dialog"
            aria-modal="true"
            aria-label="Mais funcionalidades"
          >
            <div className="flex justify-between items-center mb-5">
              <h2 className="text-lg font-bold text-[#14263d]">
                Mais funcionalidades
              </h2>

              <button
                onClick={() => setMoreOpen(false)}
                className="min-w-11 min-h-11 grid place-items-center"
                aria-label="Fechar"
              >
                <X size={22} />
              </button>
            </div>

            <div className="grid grid-cols-2 gap-3">
              {modules.map((module) => {
                const Icon = module.icon;

                return (
                  <button
                    key={module.id}
                    onClick={() => navigate(module.id)}
                    className="
                      min-h-16 p-3
                      border border-slate-200
                      rounded-xl
                      flex items-center gap-3
                      text-left
                      hover:bg-slate-50
                      active:scale-[0.98]
                    "
                  >
                    <Icon
                      size={22}
                      className="text-emerald-600 shrink-0"
                    />

                    <span className="text-sm font-medium">
                      {module.label}
                    </span>
                  </button>
                );
              })}
            </div>
          </section>
        </div>
      )}
    </>
  );
};
```

### Integração obrigatória

No arquivo `App.tsx`, manter a utilização do componente e verificar que:
